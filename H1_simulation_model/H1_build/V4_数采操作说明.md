# v4 数采操作说明（目标 300 条 · 固定点与 v3 相同 · 终末慢速）

> 一句话：**位置沿用 v3 老点不变，风格统一**。方块每次都落在 v3 一直在用的
> (0.65, ±0.30)（与 v3 数据/评测直接可比），但进近和抓取的方式每条都一样
> （给精度）。v3 失败的根源是终末动作又快又风格各异，模型学成了"每段都缩水的
> 平均动作"，最后 6~8cm 永远走不完。
>
> （出生点曾改过双臂之间的 (0.55,±0.12)、也试过随机带，均按用户要求改回 v3
> 老点；随机带基础设施保留在 `teleop/h1_spawn_zones.py` 备用。）

## 启动

```bash
cd H1_simulation_model/H1_build && ./run_record.py
```

- 数据自动落 `data/h1_build_pick_v4`（新目录，**绝不续采进 v3**）。
- 夹爪仍是斜坡约定（GRIPPER_COMMAND_SPEED=2.0，和 v3 完全一致），不用改任何东西。

## 每回合节奏

```
A 重置方块到固定点 → 等 1s 落稳 → X 开始录制 → 左右手各抓各的方块放入绿桶 → X 保存 → 再按 A 循环
```

- 录制中按 A = 丢弃当前回合（方块瞬移会污染数据）。
- B = 双臂回 home（录制中按会自动保存）。
- 目标 **300 条**；单条约 20~30 秒，分几天采完没问题，**宁可慢不可乱**。

## ★ 进近纪律（本轮数据质量的核心，比条数更重要）

1. **统一从正上方进**：先把夹爪水平移到方块**正上方** → 停稳 → **竖直**下探 → 闭合。
   禁止斜着插进去、禁止横扫蹭过去（v3 里就有这种路径，模型学会后伸臂时把方块推飞）。
2. **最后 5cm 慢**：约一掌宽的距离用约 1 秒走完——悬停 → 缓慢下探 → 闭合；
   闭住后**停半秒**再提起。
3. **放置同理**：移到桶**正上方** → 停稳 → 缓慢下探到桶口内 → 松爪 → 提起。
   不要从侧面甩进去。
4. **头部完全固定**：代码已把头部锁死在 home 姿态（yaw=0、俯仰 0.53 rad 正对桌面），
   头显不再联动头部——你转头/抬头，画面都不会动。头部相机变成一台固定的 overlooking
   相机，每条数据的视角零散射（v3 实测首帧就有 ±0.06rad 散射、回合内平均摆 0.15rad）。

## 固定出生点（A 键自动重置，不用手摆）

| | 位置（基座系） | 说明 |
|---|---|---|
| 左方块 | (0.65, +0.30) | 与 v3 完全一致 |
| 右方块 | (0.65, −0.30) | 镜像 |

- **与 v3 的出生点完全相同**——v4 与 v3 的差别只在"怎么抓"（进近纪律/终末慢速/
  头部固定），不在"在哪抓"，训练/评测直接可比。
- 头部已固定俯视 0.53 rad，双方块+绿桶仍在画面内（渲染验证过）。
- 这个点定义在 `H1_scene.xml` 的 home keyframe 里——A 键重置、rollout
  `--spawn home`、离线校验全部自动同源，不会出现数采/评测两个位置。
- 终端会打印 `A: both red cubes reset to home keyframe poses`，听到/看到即重置成功。

## 开工前自检（第一次采 v4 时做一次，约 1 分钟）

1. 按 A，等方块落稳，用最快舒适速度试抓一次（不用录制）。
2. 确认头部完全固定后画面仍是你要的习惯（头部姿态是 `H1_scene.xml` keyframe 里
   Head_j2=0.53 一行数字，要微调说一声，数采和评测两边自动同步）。
3. 其余与 v3 操作无异——本来就是你熟悉的老位置。

## 采完之后（给训练侧的备忘）

1. QC（帧率/长度/state 域/夹爪沿检查，同 v3 流程）。
2. trim 拷贝 → 重新生成 norm_stats → 训练配置数据集路径同步改 v4。
3. 训练侧加 per-dim 损失加权：右臂 7 维 + 双夹爪（对着 v3 实测偏置 R_J1/R_J4/Grip.R）。
4. 评测用 `--spawn home`（默认，= 出生点 0.65,±0.30，与数采同分布，也与 v3 几何
   直接可比）。
