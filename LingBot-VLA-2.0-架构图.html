4 Flow Matching 动作生成 (modeling_lingbot_vla_v2.py + flow_match.py)

🟢 训练 forward noise ~ N(0,I),   time ~ U(0,1)
x_t = t·noise + (1-t)·action  (动作掺噪声)
u_t = noise - action  (目标速度)
VLM+Expert 前向 → action_out_proj → v_t
vla_loss = MSE(u_t, v_t)
🟧 推理 sample_actions 1. prefix 前向 → 缓存 KV cache (只算1次)
2. x_t = 纯噪声,   time = 1.0
3. 循环 10 步去噪:
   v_t = predict_velocity (复用 KV)
   x_t += dt · v_t  (欧拉积分)
4. x_t → 动作 chunk (50步,归一化)
↓

📌 架构要点：
① VLM 骨干(Qwen3-VL 改装):看图听话,插入 depth/video 双查询
② MoE 专家(32选4 + 共享):稀疏推理,参数容量大但算得少
③ Flow Matching:训练学速度场,推理从噪声积分到动作(10步去噪)
④ 双查询蒸馏:训练时深度+视频教师监督(几何+时序理解),推理只用动作但受益于好表征
⑤ 统一 55 维空间:不同机器人映射到同一空间的不同子集,共用一个模型

一句话:RGB 图像+语言+状态 → VLM 看懂(含双查询)→ MoE 推理 → Flow Matching 走出动作 → unapply 还原 → 机器人执行
